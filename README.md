# CODSOFT Task 1: Titanic Survival Prediction

## Data Science Internship

### Project Overview

This project was completed as part of the CODSOFT Data Science Internship.

The objective is to build a machine learning model to predict whether a passenger on the Titanic survived or not based on passenger characteristics.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Project Steps

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Preprocessing
6. Train-Test Split
7. Logistic Regression
8. Random Forest Classification
9. Model Evaluation
10. Feature Importance

### Models Used

**Logistic Regression:** 80.45% accuracy

**Random Forest:** 81.56% accuracy

### Final Result

The Random Forest Classifier performed better than Logistic Regression on the test dataset, achieving an accuracy of **81.56%**.

### Conclusion

This project demonstrates the use of machine learning to predict Titanic passenger survival based on passenger characteristics. Random Forest was selected as the final model based on its performance on the test dataset.
